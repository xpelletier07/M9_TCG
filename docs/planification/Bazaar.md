### Explication générale
Le Bazaar sert à la vente et l'achat de toutes les cartes. L'écran d'acceuil est très similaire à l'écran de la collection. Par défaut, le layout qu'on voit est pour acheter les cartes. Un boutton sur le côté est affiché pour vendre des cartes, il prends une liste de toutes les cartes dans l'inventaire du joueur pour montrer les cartes qu'il peut vendre.
